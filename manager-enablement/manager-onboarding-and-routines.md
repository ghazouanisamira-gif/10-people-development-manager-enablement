# Manager Onboarding & Enablement

## Purpose

Support operational managers in understanding their role, organizing daily work, using appropriate tools and developing autonomy.

## Enablement Sequence

**Role Clarity → Operational Understanding → Priorities → Tools → Daily Routines → KPI Management → Team Follow-up → Reporting → Coaching → Autonomy**

## Practical Support

Depending on the role, the toolkit can include:

- Manager onboarding plan
- Role and responsibility clarification
- Daily / weekly management routines
- Management checklists
- Adapted To-Do Lists
- KPI review routines
- Action trackers
- Reporting templates
- Escalation mechanisms
- Team follow-up structures
- Coaching and feedback tools
- Knowledge-base resources

## Design Principle

Tools should be adapted to the manager's actual responsibilities and operating environment rather than imposed as generic administrative controls.
