# Coaching, Feedback & Debrief Framework

## Coaching Cycle

**Observe → Assess → Diagnose → Discuss → Demonstrate → Practice → Feedback → Apply → Follow Up → Reassess**

## Debrief Sheet

A structured debrief can capture:

- Context / activity
- Objective
- Observations
- Strengths
- Gaps
- Root causes
- Feedback provided
- Employee / manager perspective
- Agreed actions
- Support required
- Deadline or checkpoint
- Follow-up result
- Next development priority

## Use Cases

- Onboarding
- Coaching
- Training follow-up
- Quality reviews
- Calibration
- Post-incident learning
- Manager support
- Continuous improvement

## Coaching Principle

Coaching should build **understanding, application and autonomy**, rather than dependency on the coach.
