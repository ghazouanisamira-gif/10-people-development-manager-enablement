# Development Action & Follow-up Tracker

## Purpose

Maintain traceability between identified development needs, interventions and evidence of application.

| Date | Person / Role | Need | Root Cause | Action | Owner | Due Date | Evidence | Status | Reassessment |
|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | |

## Status

**Identified → Planned → In Progress → Applied → Verified → Closed**

## Control Principles

- Every action has an owner.
- Every action has a follow-up point.
- Closure requires evidence where appropriate.
- Overdue actions are reviewed rather than silently carried forward.

Use anonymized or role-based data in public portfolio examples.
