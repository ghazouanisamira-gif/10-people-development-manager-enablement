# Learning Path — Example

> **Demonstration / Fictional Data — not a real employee development plan.**

## Objective

Enable a newly appointed manager to independently run daily management routines and use operational KPIs to identify corrective actions.

## Learning Path

**Baseline → Learn → Practice → Apply → Feedback → Reinforce → Reassess**

| Stage | Method | Application | Evidence |
|---|---|---|---|
| Baseline | Capability assessment | Identify gaps | Assessment completed |
| Learn | KPI management module | Interpret 4 core indicators | Knowledge check |
| Practice | Guided dashboard exercise | Diagnose fictional performance trends | Completed exercise |
| Apply | Weekly management routine | Run review independently | Observation |
| Feedback | Coaching session | Correct gaps | Coaching record |
| Reinforce | Job aid + micro-learning | Repeat routine | Follow-up |
| Reassess | Capability review | Verify autonomy | Reassessment |

## Success Criterion

The learner can independently interpret the dashboard, identify a priority issue, propose an evidence-based action and document follow-up.
