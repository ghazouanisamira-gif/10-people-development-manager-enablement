# Coaching Plan — Example

> **Demonstration / Fictional Data — not a real coaching record.**

## Coaching Objective

Improve a manager's ability to convert KPI signals into structured team actions.

## Baseline Evidence

The manager identifies KPI deterioration but actions are often generic and are not consistently followed through.

## Coaching Cycle

**Observe → Diagnose → Demonstrate → Practice → Feedback → Apply → Follow Up → Reassess**

| Session | Focus | Coaching Action | Practice | Follow-up |
|---|---|---|---|---|
| 1 | KPI diagnosis | Demonstrate root-cause questioning | Analyse fictional case | Review action quality |
| 2 | Action planning | Practice owner/deadline/evidence logic | Build action tracker | Observe application |
| 3 | Follow-up | Coach on verification | Review completed actions | Reassess autonomy |

## Reassessment

**Evidence:** manager independently identifies root cause, assigns an appropriate action and defines verification evidence.

**Next priority:** transfer the method to more complex operational situations.
