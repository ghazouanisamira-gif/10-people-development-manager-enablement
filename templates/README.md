# Reusable Templates

This folder is the future home for anonymized, reusable tools such as:

- Level / competency assessment
- Skills matrix
- Training Needs Analysis
- Individual Development Plan
- Coaching sheet
- Debrief / feedback sheet
- Manager onboarding checklist
- Management To-Do List
- Learning plan
- Knowledge check
- Team-building plan
- Follow-up and reassessment tracker

Templates should be added progressively, validated for confidentiality and designed for reuse across operational, quality and transformation contexts.
