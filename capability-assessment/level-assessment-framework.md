# Capability & Level Assessment Framework

## Purpose

Establish a structured baseline of capability before defining development actions.

## Assessment Dimensions

- Technical knowledge
- Process knowledge
- Methodology
- Tool proficiency
- Quality standards
- Communication
- Problem solving
- Organization and prioritization
- Analytical ability
- Management practices
- Coaching capability
- Decision-making
- Stakeholder interaction
- Autonomy

## Progression Model

**Awareness → Basic Application → Operational Proficiency → Advanced Application → Autonomy / Transfer**

## Assessment Logic

**Evidence → Current Level → Expected Level → Gap → Root Cause → Development Need**

Assessment should rely on observable evidence rather than assumptions.

## Confidentiality

Use anonymized examples and never publish individual employee records or identifiable assessment results.
