# Capability & Performance Development Cycle

## Integrated Cycle

**Performance Signal → Assessment → Root-Cause Analysis → Capability / Process Diagnosis → Intervention → Application → Measurement → Standardization → Continuous Improvement**

## Evidence Sources

- KPI trends
- Quality results
- Observation
- Coaching records
- Debrief outcomes
- Calibration
- Manager feedback
- Process deviations
- Reporting quality
- Reassessment results

## Intervention Selection

The response should match the diagnosis:

| Diagnosis | Possible response |
|---|---|
| Knowledge gap | Training / learning module |
| Skill gap | Guided practice / coaching |
| Methodology gap | Demonstration / job aid |
| Tool gap | Tool enablement / support |
| Process gap | Process improvement |
| Role-clarity gap | Role clarification / manager enablement |
| Workload / organization issue | Planning / workload adjustment |
| Governance issue | Management routine / escalation |

## Sustainability

Every intervention should include a follow-up point and, where appropriate, reassessment and standardization of effective practices.
