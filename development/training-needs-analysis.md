# Training Needs Analysis

## Purpose

Identify whether a performance or capability gap requires a learning intervention and what type of intervention is appropriate.

## Inputs

- Level and competency assessments
- KPI trends
- Quality evaluations
- Calibration results
- Observation
- Manager feedback
- 1:1 discussions
- Incidents and process deviations
- Reporting quality
- Recurring questions or errors
- Onboarding observations
- Self-assessment

## Diagnostic Logic

**Evidence → Gap → Root Cause → Development Need → Intervention**

Potential causes should be distinguished between knowledge, skill, methodology, tool, process, organization/prioritization, role clarity, communication/stakeholder management, management system, workload and environment.

## Principle

**Diagnose before training.**

Training should not compensate for a broken process, inadequate tool, unclear responsibility or systemic constraint.

## Possible Interventions

- Coaching
- Training module
- Micro-learning
- MOOC-style learning sequence
- Job aid
- SOP / work instruction
- Guided practice
- Workshop
- Calibration
- Manager enablement
- Process improvement
- Tool support
- Follow-up and reassessment
