# Learning & Development Toolkit

## Learning Formats

- Structured training modules
- E-learning
- Micro-learning
- MOOC-style learning sequences
- Practical workshops
- Guided exercises
- Case studies
- Simulations
- Role plays
- Demonstrations
- Job aids
- Quick-reference guides
- SOPs / work instructions
- Knowledge checks
- Refresher sessions
- Train-the-trainer approaches
- Peer learning
- Calibration

## Learning Cycle

**Learn → Practice → Apply → Observe → Feedback → Reinforce → Reassess**

Learning is considered effective when knowledge is transferred into observable application and sustained practice.
